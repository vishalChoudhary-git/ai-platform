# 18 — Communication & Technical Leadership

**Target:** Advanced

## Topics

- Mentoring
- Stakeholder communication
- Requirements gathering

- Prioritization

## Practice
For every major project, write a concise architecture/design document, explain the trade-offs, communicate risks and own the outcome from design through production.
