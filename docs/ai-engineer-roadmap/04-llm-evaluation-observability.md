- Context relevance, context precision and context recall
- Faithfulness and answer relevance
- Citation accuracy
- Agent task success
- Tool selection/execution accuracy
- Planning and trajectory evaluation
- Cost per task and step count
- Hallucination and factuality
- Safety, toxicity and bias evaluation
- Structured output correctness
- Logging, metrics and tracing

- LLM, prompt, retrieval and tool traces

- A/B testing

## Practice
Create an evaluation harness for RAG and agents and connect traces to quality, latency, token usage and cost so every AI change can be measured.
