# 02 — Production RAG

**Target:** Expert

## Topics
- Document ingestion: PDF, DOCX, PPTX, XLSX, HTML and images
- OCR and scanned documents
- Layout-aware parsing
- Tables, sections, lists, links and embedded images
- Metadata extraction
- Fixed, recursive, semantic, sentence and paragraph chunking
- Markdown/document-aware chunking
- Hierarchical and parent-child chunks
- Context-aware chunking
- Dense, sparse and multilingual embeddings
- Embedding dimensions and normalization
- Cosine, dot-product and Euclidean similarity
- Embedding versioning
- PostgreSQL + pgvector
- Pinecone, Weaviate, Qdrant, Milvus concepts
- HNSW, IVFFlat and approximate nearest-neighbor search
- Vector, keyword/BM25 and hybrid search
- Metadata filtering
- Query expansion and rewriting
- Multi-query retrieval
- HyDE
- Parent-child and hierarchical retrieval
- Self-query retrieval
- Cross-encoder and LLM reranking
- Context compression
- Corrective, adaptive, Self-RAG, Graph RAG and Agentic RAG
- Multi-hop and conversational retrieval
- Permission-aware retrieval
- Document ACLs
- Tenant isolation and PII filtering
- Recall@K, Precision@K, MRR, NDCG
- Context relevance, faithfulness, answer relevance and citation accuracy

## Practice
Build and evaluate an enterprise document intelligence + RAG pipeline with permissions, hybrid retrieval, reranking, citations and measurable retrieval/answer quality.
