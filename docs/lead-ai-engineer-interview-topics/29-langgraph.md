# Topic 29 — LangGraph

**Status:** Planned

## Focus
LangGraph fundamentals for production agent workflows: state, nodes, edges, conditional routing, loops, persistence/checkpointing, streaming, human-in-the-loop, durable execution, tool calling and failure handling.

## Interview outcomes
Explain when a graph-based orchestration runtime is preferable to a simple chain or a higher-level agent framework, and how a LangGraph workflow could fit into the AI Platform.

## Project connection
Map LangGraph concepts to the AI Platform's planned agentic workflows. Reuse existing abstractions for retrieval, storage, embeddings, reranking and model providers rather than coupling the graph to infrastructure implementations.

## Current ecosystem note
LangGraph is currently positioned as a lower-level orchestration framework/runtime for long-running, stateful agents, with capabilities such as durable execution, streaming, human-in-the-loop and persistence.
