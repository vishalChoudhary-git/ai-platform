# Travel Agent Extension

This extension is the hands-on sandbox for the Agentic AI course.

## Day 11 — Plan-and-Execute

Implement the Travel Agent yourself using the concepts learned so far:

- LangGraph state
- Nodes and edges
- Conditional routing / loops
- Plan-and-Execute
- Short-term memory / checkpointing
- Human-in-the-loop

The learning sequence is intentional:

```text
Teacher concept
    ↓
Understand why it exists
    ↓
Design the graph
    ↓
Write the code yourself
    ↓
Review behavior and trade-offs
    ↓
Extend beyond the teacher's implementation
```

Do not copy a prebuilt implementation into this extension. The purpose is to make the architecture and framework concepts yours.
